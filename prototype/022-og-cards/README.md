# Prototype 022: OG cards

Three Open Graph card looks (A yellow, B ink, C off-white), 4 cards each, rendered with Satori + resvg. All text is stand-in.
Run: `npm install && npm run og` (writes 12 PNGs to `out/`).
Open `index.html` (switch surface with the bottom bar or `?v=a|b|c`).
Overflow check: headline or subtitle over 2 lines makes `npm run og` exit non-zero.
